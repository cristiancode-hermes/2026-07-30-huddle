# Huddle 🔥

Social Activity Organizer for Friend Groups.

Plan hangouts, suggest activities, vote on dates, and build memories — without the group chat chaos.

## Stack

- **Frontend:** Angular 22 (signals, zoneless, standalone)
- **Backend:** NestJS 11 + TypeORM + SQLite/PostgreSQL
- **Auth:** JWT with Passport.js + bcryptjs
- **Styling:** CSS Custom Properties (design system)

## Quick Start

```bash
npm install
cd apps/api && npm run start:dev
cd apps/web && npm run start
```
